# Desk Focus Timer

A compact desktop productivity timer built with Python and Tkinter.

## Always-on-top display

Desk Focus Timer is designed to appear as a **floating overlay above the main application window**. It can be:

- Kept on top of other windows
- Moved anywhere on the desktop
- Expanded to show timer controls
- Reduced back to a compact timer view

This makes it useful as a small visual timer while working in other applications.

> In desktop UI terminology, this is called an **always-on-top floating window**, **desktop overlay**, or **widget**.

## Features

- Work-session stopwatch
- Countdown timer
- 5-, 10-, and 20-minute presets
- Custom countdown durations
- Start, pause, stop, and reset controls
- Expandable compact interface
- Draggable window
- Resizable window

## Run

```powershell
python main.py
```
